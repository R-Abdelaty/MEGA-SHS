# MEGA-SHS project rules

- Build the frontend with React and Vite.
- Use JavaScript only; do not add TypeScript.
- Use plain CSS only; do not add Tailwind CSS.
- Keep the monthly calendar implementation code-native; do not add a calendar
  library.
- Keep backend/API access inside `frontend/src/services/`.
- Preserve the design system defined in `frontend/src/styles/variables.css`:
  green backgrounds, cream surfaces, muted green event bars, charcoal text,
  warm coral accents, and a consistent rounded control treatment.
- Maintain functional desktop and mobile layouts.
- Keep the calendar as the primary visual area.
- Do not modify the existing Python scheduling backend unless a future task
  explicitly requests backend work.
